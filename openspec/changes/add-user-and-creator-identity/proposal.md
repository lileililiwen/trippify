# Why
Travelers and creators need secure identities and distinct public/private profiles before guides can be owned or sold.

# What Changes
- Add registration, login, logout, recovery, verification, and profile management.
- Add creator enrollment and public creator profiles.
- Add administrator-managed account and creator status controls.

# Capabilities
## New Capabilities
- `user-creator-identity`: Identity, profiles, creator status, and public creator presence.

# Dependencies and Non-goals
- Dependencies: `establish-platform-foundation`.
- Non-goals: guide authoring, follows, payouts, and sales analytics.

# Impact
Adds identity tables, authenticated Flutter flows, creator pages, and authorization policies.
